## 🚀 Getting Started

### 1. Prerequisites
- Node.js 18.x or 20.x
- npm 9+

### 2. Installation
```bash
git clone git@github.com:musab-zaighum/nexus-rank-1-private.git
cd nexus-rank-1-private
npm install
```

### 3. Environment Configuration
Create a `.env.local` file:
```env
NEXT_PUBLIC_WHOP_CHECKOUT_URL="https://whop.com/checkout/nexusrank1-clinic-growth"
NEXT_PUBLIC_PRACTICE_WEBHOOK_URL="https://your-pms-or-crm-webhook-url"
```

### 4. Local Development
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view the live practice growth platform.

### 5. Production Build
```bash
npm run build
npm run start
```
