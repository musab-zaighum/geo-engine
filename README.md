# NexusRank1.com (`nexus-rank-1`)

> **Autonomous B2B White-Label Micro-SaaS Platform for Marketing Agencies**

NexusRank1.com is a mobile-compatible, high-converting Next.js and Tailwind CSS platform engineered to act as an automated sales engine for boutique marketing agencies. It proves SEO/GEO value in 5 seconds and enables agencies to sell recurring clinical schema & `/llms.txt` retainers with **93%+ net margins**.

---

## ⚡ The 5-Part Conversion Engine

1. **Mobile-Optimized Instant Audit Bar**
   - Single-tap URL input (`type="url"`, `autoCapitalize="none"`, `autoCorrect="off"`).
   - Quick benchmark presets (`dentalpractice.com`, `mayoclinic.org`, `clevelandclinic.org`).
   - 5-Second Fake-Progress Visualizer displaying 5 scanning stages with glowing laser progress bar.
   - Thumb-friendly score card showing 84/100 readiness score, Grade B+, 4 visual health meters, and plain-English diagnostic cards.

2. **The "One-Click Copy & Google Test" Button**
   - Tactile `[ Copy 0-Error Schema ]` button with green checkmark feedback (`✓ Copied 0-Error Schema!`).
   - Direct external link button `[ Validate on Google Rich Results Test ↗ ]`.
   - Download `/llms.txt` button & pre-filled webmaster mailto template.

3. **Interactive Agency Profit Calculator**
   - Real-time client count slider (1–50 clients) and retainer rate slider ($300–$1,500/mo).
   - Dynamic real-time calculation of client revenue, $297 NexusRank wholesale cost, and **93%+ net margin**.
   - High-converting CTA button: `[ Claim Your $297/mo Wholesale License ]`.

4. **White-Label Preview Modal & CNAME Configurator**
   - Agencies input their agency name, custom CNAME subdomain (`audit.youragency.com`), and brand palette.
   - Live interactive mockup showing what client reports look like with **zero vendor footprints**.
   - Strict Branding Rule: 100% unbranded reports strictly gated for higher tiers.

5. **Mobile In-App Checkout Integration (Whop / Apple Pay / Google Pay)**
   - Fast, thumb-friendly checkout drawer optimized for mobile web views (Instagram, LinkedIn, Twitter/X, mobile Safari/Chrome).
   - 1-Tap Apple Pay (Pay), Google Pay (GPay), and Whop / Card buttons.
   - 4-Second frictionless subscription closure simulation with instant master license key delivery (`NR1-GROWTH-XXXX`).

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Local Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view the landing page and conversion engine.

### 3. Build for Production
```bash
npm run build
npm run start
```
