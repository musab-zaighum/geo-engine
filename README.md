## 🚀 Dual Deployment: Next.js + Netlify Drop

### Option A: Netlify Drop (Instant Drag-and-Drop)
The repository includes an automated static builder generating a self-contained bundle ready for Netlify Drop:
```bash
# Build the static Netlify package
npm run build
```
1. Open [app.netlify.com/drop](https://app.netlify.com/drop) in your browser.
2. Drag and drop the generated `dist-netlify/` directory.
3. Your clinical audit site is live globally on Netlify's high-speed Edge CDN in under 10 seconds.

### Option B: Next.js Production Server
```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Run production build and server
npm run build
npm run start
```
